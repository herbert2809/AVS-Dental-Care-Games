# Dental Care Games

Classroom games for the AVS Open House lesson "Unit 5: Dental Care" (Amazing Science 1, Grade 1).
The games are made for one shared screen and four teams: Red, Blue, Green and Yellow.

## Games

| File | Game | Lesson stage |
| --- | --- | --- |
| `index.html` | Home page with all games | |
| `game1-good-or-bad.html` | Good or Bad for Your Teeth? Eight numbered tiles | Lead-in |
| `game2-listen-and-tap.html` | Listen and Tap. Four listening questions | Presentation |
| `game3-happy-or-sad-tooth.html` | Happy Tooth or Sad Tooth? Eight cards to sort | Practice |
| `game4-pop-and-say.html` | Pop and Say. Pop the bubbles to show one of eight pictures | Practice |
| `game5-lucky-tooth.html` | Lucky Tooth. Four teeth, one for each team | Production |
| `timer.html` | Countdown timer, set to 4 minutes | Production |

## How to use

- Online: open the GitHub Pages link of this repository.
- Offline: download the HTML files and open `index.html` in Chrome or Edge. Each file works without internet.
- Team scores stay on the screen from game to game. Use "Reset scores" before a new class.
- Use the small + and − buttons beside a score to correct it by hand.

## Editing

The files in the main folder are built from `src/`. After changing anything in `src/`, run `python3 build.py`.
All pictures are original drawings made for these games.
